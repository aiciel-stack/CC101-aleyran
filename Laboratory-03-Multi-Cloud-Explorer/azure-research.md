# Microsoft Azure 

## Brief Overview
Microsoft Azure is a cloud computing platform launched by Microsoft in 2010. Azure is known for its deep integration with Microsoft's existing enterprise software ecosystem, including Windows Server, Active Directory, and Microsoft 365. It is one of the top three public cloud providers globally and is a popular choice for organizations that already rely heavily on Microsoft products.

## Global Infrastructure
Azure's infrastructure is built around *Regions* (geographic areas containing one or more datacenters) and *Availability Zones* (physically separate locations within a region that protect against datacenter-level failures). Azure also groups regions into *Region Pairs* for disaster recovery purposes, ensuring that data replicated between paired regions stays within the same geography for compliance reasons. Azure also has an extensive global network of edge sites through Azure Front Door and Azure CDN for content delivery.

## Cloud Management Console
The *Azure Portal* is the primary web-based interface for managing Azure resources, offering dashboards, resource groups, and monitoring tools. Azure also provides the *Azure CLI* and *Azure PowerShell* for scripting and automation, along with *Azure Resource Manager (ARM)* templates for infrastructure-as-code deployments. Identity and access are managed through *Microsoft Entra ID* (formerly Azure Active Directory).

## Four (4) Core Services
1. *Azure Virtual Machines* – On-demand, scalable virtual servers similar to AWS EC2, supporting both Windows and Linux operating systems.
2. *Azure Blob Storage* – Object storage service for unstructured data such as documents, images, and backups.
3. *Azure SQL Database* – A fully managed relational database service built on Microsoft SQL Server technology, with automatic patching, backups, and scaling.
4. *Microsoft Entra ID (Azure AD)* – A cloud-based identity and access management service that integrates tightly with on-premises Active Directory environments.

## Three (3) Advantages
1. *Seamless Microsoft integration* – Azure integrates natively with Windows Server, Microsoft 365, and Active Directory, making it ideal for organizations already using Microsoft technologies.
2. *Strong hybrid cloud support* – Services like Azure Arc and Azure Stack allow organizations to extend on-premises infrastructure into the cloud smoothly.
3. *Enterprise and compliance focus* – Azure offers extensive compliance certifications and enterprise agreements, appealing to large organizations, government, and regulated industries.

## Typical Enterprise Use Cases
- Migrating existing Windows Server and Active Directory environments to the cloud.
- Running hybrid cloud environments that combine on-premises and cloud resources.
- Enterprise application hosting (e.g., SAP, SharePoint, Dynamics 365).
- Business intelligence and analytics through Power BI and Azure Synapse Analytics.
- Identity and access management for organizations with Microsoft 365 subscriptions.
