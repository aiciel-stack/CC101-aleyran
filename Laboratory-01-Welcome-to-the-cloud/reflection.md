Reflection

This laboratory activity helped me understand the importance of Linux and GitHub in cloud computing. I realized that before managing cloud-based systems, it is necessary to become familiar with the Linux environment and learn how to navigate and monitor a system using the terminal.

During the activity, I practiced creating a user account and using different Linux commands, including `whoami`, `pwd`, `hostname`, `lsb_release`, `lscpu`, `free`, and `df`. These commands allowed me to identify system details such as the current user, operating system, processor, memory, and available disk space. I learned that simple terminal commands can provide useful information when monitoring and managing servers.

Another important lesson I gained was the value of proper organization and documentation. Creating Markdown files and arranging them correctly in a GitHub repository helped me see how technical work can be presented in a clear and professional way.

One challenge I encountered was following the required file and folder structure. I had to carefully check the names and locations of each file because even small errors could affect the overall organization of the repository.

Overall, this activity improved my confidence in using Linux and GitHub. It also gave me a better understanding of the skills needed before moving on to more advanced cloud technologies such as Docker and Kubernetes.
