Welcome to the Cloud- Laboratory 1

Mission Overview

Laboratory 01 introduced the basic environment and responsibilities involved in cloud infrastructure management. The activity focused on using KillerCoda to access an Ubuntu Linux environment, performing basic system administration tasks, organizing project files, and documenting the completed work through GitHub.

Objectives

* Set up and access an Ubuntu cloud-based environment
* Practice basic Linux navigation and administration
* Collect important information about the system
* Create and manage directories and files through the terminal
* Develop a properly organized GitHub repository
* Record and present technical activities using Markdown

Activities Completed

1. Started an Ubuntu 24.04 cloud environment through KillerCoda.
2. Created a separate Linux user account with administrative privileges.
3. Used terminal commands to examine the operating system, kernel, CPU, memory, and storage.
4. Built an organized directory structure containing Documents, Notes, Reports, and Screenshots.
5. Created an `about-me.md` file to provide personal information and project details.
6. Set up a public GitHub repository and arranged the required files and folders.
7. Recorded the progress of the laboratory through screenshots and Markdown documentation.
8. Used Git commands to add, commit, and upload the completed work to GitHub.

Linux Commands Practiced

- sudo adduser, usermod -aG sudo, su
- whoami, pwd, hostname
- cat /etc/os-release, uname -r, lscpu, free -h, df -h
- mkdir, touch, nano, ls, cat
- git clone, git add, git commit, git push

Skills and Knowledge Gained

Through this laboratory, I gained practical experience in basic Linux system administration and cloud environment management. I learned how to create users, manage permissions, inspect system resources, and organize files using terminal commands. I also improved my understanding of Git and GitHub, particularly in maintaining a structured repository and tracking project changes. Most importantly, the activity demonstrated how Linux, documentation, and version control work together in a cloud infrastructure environment.
