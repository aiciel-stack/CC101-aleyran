# System Baseline Report

## Memory (RAM)
Command used: `free -h`
- Total RAM available: (read the "total" column of the Mem: row, e.g. "1.9Gi")

## Disk Storage
Command used: `df -h`
- Total storage capacity of the root (/) file system: (read the "Size" column of the / row, e.g. "20G")

## Why Check Disk Space Before a Traffic Surge
Running out of disk space during a traffic surge can cause the web server to fail to write logs, cache files, or temporary data, crashing the application even if CPU and memory are fine.
