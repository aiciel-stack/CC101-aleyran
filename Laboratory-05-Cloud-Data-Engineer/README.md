# Laboratory 5: The Cloud Data Engineer

## Mission Overview
In this mission, I was reassigned to the Cloud Data Engineering Team at CloudNova Technologies. I researched the differences between block, file, and object storage, then used Docker in a KillerCoda Ubuntu playground to deploy MinIO, an S3-compatible object storage server. I accessed its web console, created a bucket named client-photos, and uploaded a test file as a proof of concept for a client's photo-sharing application.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible object storage server (MinIO) using Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload objects (files).
- Document cloud storage operations using Markdown.
- Continue expanding my GitHub Cloud Computing Portfolio.

## Tools Used
- KillerCoda Playground (Ubuntu)
- Docker
- MinIO (S3-compatible object storage)
- MinIO Web Console
- GitHub
- Markdown
- Web browser

## Skills Learned
- Explaining the differences between block, file, and object storage and their use cases.
- Deploying a containerized service using Docker with environment variables.
- Mapping multiple ports and accessing a web service through KillerCoda port forwarding.
- Creating a bucket and uploading objects using the MinIO web console.
- Verifying a running container with `docker ps`.
- Documenting technical configurations clearly in Markdown and organizing them in GitHub.
